About the Project

This project is my personal take on Build for Good (BFG) 2024, a yearly citizen hackathon organized by the Singapore Government. For this year, one focus area is "Reducing packaging and food waste, and encouraging recycling".

Singapore's domestic recycling rate has been falling for the past few years, and Singapore's current waste management infrastructure takes time to change. I believe there is an opportunity for residents to improve the situation through cooperation.

To address the focus area in BFG, my solution, Challenge Together, is a community challenge app envisioned to be part of the Singapore government's One Service app. This app is used to administer a Recycling Challenge, where residents cooperate to hit recycling rate targets to collect points that can be converted to vouchers, thus encouraging recycling. How it works:

Consumer-facing features in Challenge Together:

  1. Challenge info page, with "join" and "share" functions
  2. Group chat for residents to facilitate collaboration
  3. Metrics that display the estate's and the individual's weekly performance in the challenge
  4. Points-to-Voucher claim flow

Admin Portal features in Challenge Together:

Problem Solving Highlights

Tracking Residents' Weekly Contributions

Problem: Requires a mechanism to track participation and contributions without relying on self-reporting (to avoid potential cheating).

Solution: QR code chosen, as it does not require user to fill in information.

  1. Generate QR code in SVG format using RQRCode Ruby Gem
  2. Upon scanning the QR code during recycling event, users redirected to a page with all information pre-filled for acknowledgement.

Note: For demo purposes, the recyclable weight is mocked using a random number generator.

Update of Challenge Performance Metrics

Problem: For effective collaboration via a feedback loop, residents need to know the estate's and their own latest performance. This requires:

  • Weekly post event tallying of metrics
  • Display of metrics into dashboard / chart format

Solution: Create a Rails Active Job that performs computationally expensive calculations after the event:

  1. Sum up the total recyclable weight of estate
  2. Sum up the total waste of estate (assume 6kg / resident)
  3. Calculate the recycling rate from (1) and (2)
  4. Check if recycling rate meets any target
  5. Disburse the corresponding points to participants in the estate
  6. Update the user's total points in the database

Admin user can run the Rails Active job by pressing a button.

Visualise data using Chart.js:

  1. a JavaScript function on the View would call my Controller's backend method (using "fetch")
  2. the backend method would compute the data required and respond in JSON
  3. upon receipt of the resolved promise, JavaScript function destructures the JSON and extracts the data in array format, then used in the Chart object

The resultant output is a simple chart describing the last 6 weeks' challenge performance.
