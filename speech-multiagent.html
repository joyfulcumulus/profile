About the Project

This is a group project for CS614 Generative AI with LLMs course.

In this project, we built a multi-agentic system which helps a user turn a speech outline into a professional script based on TED-talk best practices, while personalised to the user's style. Features of our system:

  • Verification of factual claims, with Human in the Loop (HITL) for correction
  • Speech content enrichment using Tavily Search with strong evidence
  • Maker-checker loops in architecture to improve quality of output at each stage
  • Schema validation of agentic output using Pydantic to ensure clean inputs to next stage
  • Final LLM-as-judge evaluation for improved coherence and quality
  • Containerised in Docker for scalable and reliable deployment

Multi-agentic system flow:

A. Content verification and structural improvements. This is done using Tavily to conduct web search and verify facts, Tavily to retrieve stronger and more relevant facts, prompt engineering to apply TED Talk structure to create a more engaging speech:

B. User's style incorporation. This is done by analysing samples of past speeches made by the user to arrive at a style profile, which is then applied to the content outline:

My Role

  • Developed agents of Part B of the flow, which includes: style extraction, style aggregation, script writing, and reflection agents
  • Designed and built the evaluation pipeline (manual) for the above style portion
