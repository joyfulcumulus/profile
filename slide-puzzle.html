Game Layout Design

I applied my learnings from 2048 Clone project to have similar Grid and Tile React components. The WinAlert and Button are additional components improving the user experience.

React Components

  • Grid: gameboard of the game
  • Tile: the clickable / moveable elements of the game
  • WinAlert: the notification that pops up when the player has won
  • Button: to reset gameplay when the user wants to restart halfway / or wins

Structuring State

  • App component holds game progress ("progress" state) so it knows when to restart the game, or display winning alert. It has 3 allowed values - 0: start, 1: in progress, 2: won
  • Grid component holds information about tiles placement ("tiles" state). This is stored as a 1-dimensional array. As Grid component has knowledge of all tiles, it contains validation and movement logic (e.g. canMove, moveTile)

    • Why 1 dimensional array for "tiles" state?

    • Easy to check for winning condition (i.e. check numbers in ascending order) as compared to 2-dimensional array
    • Slightly more space-efficient: the (x,y) position of the Tile can be derived from the index of the array using division and modulus operators

Tile component, Button component, WinAlert component do not own any state. They have event handlers attached, which changes the "progress" and "tiles" state based on user interaction.

Problem Solving Highlights

Check Winning Condition after Player Move

When the player clicks on a tile, I checked for the winning condition (checkIfPlayerWins) in the event handler after the tile was moved. However, the function was returning the correct result only after I had made an additional click after the winning move.

Upon investigation, the root cause was React had not updated the "tiles" state when the moveTile function called setTiles(newTiles). It would only be updated in the next render. Therefore, checkIfPlayerWins result was based on the old state of "tiles", which would only give the correct result after the next render when I clicked again.

Solution: I shifted the checkIfPlayerWins into a useEffect hook, which executed after "tiles" state updated.
